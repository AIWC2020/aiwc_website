Access token

Publishing writes straight to GitHub, which needs a token with permission to change this repository. It is stored only in this browser and is never sent anywhere but api.github.com.

  1. Open the pre-configured token page — name, repository access and Contents: Read and write are already filled in.
  2. Set Expiration, then Generate token and copy it.
  3. Paste it below.

Save manually

For when you would rather not hold a token — GitHub does the authentication because you are already signed in there.

  1. Copy the JSON below (the button does it).
  2. Open the file on GitHub — the second button.
  3. Select everything in GitHub's editor (Ctrl/Cmd+A), paste, then Commit changes.

The site rebuilds automatically — your change is live in about 40 seconds. If the JSON is ever malformed the build fails and the live site keeps serving the last good version.
